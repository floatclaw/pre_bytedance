# 单个神经元学习 AND 门

本目录包含两个用 Python 实现的极简案例，都训练单个神经元学会 AND 门，但用了不同的学习方法。

## 文件

- `train_and.py`：用**感知机学习规则**训练。不显示梯度，直接根据错误调整参数。
- `train_and_with_backprop.py`：用**反向传播 + 梯度下降**训练。内部实现了一个迷你自动微分引擎，展示梯度是如何计算和使用的。

## 运行

### 感知机规则版本

```bash
cd micrograd_learning_site/examples/single-neuron-and
python3 train_and.py
```

### 反向传播版本

```bash
cd micrograd_learning_site/examples/single-neuron-and
python3 train_and_with_backprop.py
```

## `train_and.py`：感知机规则

### 代码结构

`train_and.py` 中把单个神经元抽象成了 `SingleNeuronModel` 类，接口和一个完整神经网络模型一致：

- `__init__`：初始化参数（权重和偏置）。
- `forward(x)`：前向传播，计算 `z = w·x + b`。
- `predict(x)`：根据 `z` 输出 0 或 1。
- `train_step(samples)`：用感知机规则更新一次参数。
- `fit(samples, max_epochs)`：循环训练直到收敛。
- `evaluate(samples)`：在样本上验证预测结果。

这种抽象的好处是：虽然这里只有一个神经元，但模型的结构（参数、前向、训练、评估）和更复杂的多层网络是一样的。

## `train_and_with_backprop.py`：反向传播版本

### 和感知机版本的区别

这个版本手动实现了一个迷你的自动微分引擎 `Value` 类，和 micrograd 的核心思想一致：

- 每个运算都记录子节点和局部导数。
- 调用 `loss.backward()` 自动把梯度传回每个参数。
- 用 `p.data -= lr * p.grad` 更新参数。

模型结构：`输出 = sigmoid(w1*x1 + w2*x2 + b)`，损失函数是均方误差 `(pred - y)^2`。

### 关键代码流程

```python
loss = model.compute_loss(samples)  # 前向：计算损失
loss.backward()                      # 反向：自动求梯度
for p in model.parameters():
    p.data -= lr * p.grad            # 更新：梯度下降
model.zero_grad()                    # 清零：准备下一轮
```

## 核心思想

1. **模型**：单个神经元 `输出 = sigmoid(w1*x1 + w2*x2 + b)`。
2. **损失**：预测值和真实值之间的差距。
3. **反向传播**：自动计算损失对每个参数的梯度。
4. **梯度下降**：沿负梯度方向更新参数，让损失越来越小。
5. **收敛**：因为 AND 是线性可分的，最终能找到正确分开两类样本的参数。

## 两个版本的关系

| | 感知机规则 | 反向传播 |
|---|---|---|
| 更新依据 | 预测对错 | 损失函数的梯度 |
| 是否可扩展到复杂网络 | 不易 | 容易 |
| 是否展示梯度 | 否 | 是 |
| 是否使用自动微分 | 否 | 是（手动实现） |

感知机规则更直观，适合入门；反向传播是神经网络真正的训练方法，也是 micrograd 的核心能力。
