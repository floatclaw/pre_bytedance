前置知识：神经网络是什么

如果你完全没接触过神经网络，不用慌。micrograd 本身只有 150 行代码，但它背后想解决的问题是「如何让计算机像人一样从数据中学习规律」。这一节用最少的概念帮你铺好背景。

0.1 从一个例子开始

假设你要写一个程序判断一张图片是不是猫。传统编程的做法是：

  1. 程序员观察猫的特征（尖耳朵、胡须、圆眼睛）
  2. 手动写很多 if-else 规则
  3. 发现规则太多、太复杂，根本写不完

神经网络的做法完全不同：

  1. 准备很多猫和非猫的图片，标注好答案
  2. 让模型自己从图片中总结规律
  3. 模型通过「试错」不断调整内部参数，越调越准

一句话：神经网络不是人写规则，而是用数据「调」出来的函数。

0.2 神经元：最小的计算单元

神经网络的最小单位叫神经元（neuron），它做的计算非常简单：

输出 = 激活函数( w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b )

其中：

  • x₁, x₂, ..., xₙ：输入，比如图片的像素值、一句话的编码
  • w₁, w₂, ..., wₙ：权重（weight），表示每个输入的重要性
  • b：偏置（bias），决定神经元是否更容易被激活
  • 激活函数：给神经元引入非线性，否则多层叠加也只是一条直线

类比：神经元就像一个投票器。每个输入投一票，权重表示这票的分量，偏置是「通过门槛」，激活函数决定最终是「强烈支持」还是「弃权」。

具体例子：一个神经元在算什么？

假设一个神经元有两个输入：

  • 输入 x₁ = 0.5，对应权重 w₁ = 0.2
  • 输入 x₂ = -1.0，对应权重 w₂ = 0.4
  • 偏置 b = -0.1，激活函数用 tanh

计算过程如下：

  1. 加权求和：z = w₁·x₁ + w₂·x₂ + b
    z = 0.2 × 0.5 + 0.4 × (-1.0) + (-0.1) = 0.10 - 0.40 - 0.10 = -0.40
  2. 激活函数：output = tanh(-0.40)
    output ≈ -0.3799

所以这个神经元的最终输出约是 -0.38。训练时，我们会根据这个输出和真实答案的差距，去调整 w₁、w₂、b 三个参数。

0.2.1 神经元能表示什么？以逻辑门为例

单个神经元已经能表示一些简单规律。假设输入只能是 0 或 1，激活函数用「大于 0 输出 1，否则输出 0」的简化模型：

AND 门：两个输入都为 1 时才输出 1。

  • 权重：w₁ = 1, w₂ = 1
  • 偏置：b = -1.5
x₁ x₂ z = x₁ + x₂ - 1.5 输出
0 0 -1.5 0
0 1 -0.5 0
1 0 -0.5 0
1 1 0.5 1

OR 门：只要有一个输入为 1 就输出 1。

  • 权重：w₁ = 1, w₂ = 1
  • 偏置：b = -0.5

你可以自己验证：只有 (0,0) 时输出 0，其余三种情况都输出 1。

XOR 门：两个输入不同时输出 1。

这是单个神经元做不到的。无论你选什么权重和偏置，单个神经元只能画一条直线把平面分成两半，而 XOR 的四个点（00、01、10、11）无法用一条直线把「相同」和「不同」分开。

结论：单个神经元只能解决线性可分问题，复杂问题需要把多个神经元组合成网络。

0.2.2 它是怎么学会 AND 的？

前面我们直接给出了能表示 AND 的权重，但真实训练时这些权重是从随机值开始，通过不断试错慢慢调出来的。下面看一个完整过程。

初始状态

w₁ = -0.8,  w₂ = -0.8,  b = -1.0
学习率 lr = 0.3

初始时，4 个样本的预测都是 0（因为 b 很负，很容易让 z ≤ 0）：

x₁ x₂ z = w₁x₁ + w₂x₂ + b 预测 目标
0 0 -1.0 0 0 ✅
0 1 -1.8 0 0 ✅
1 0 -1.8 0 0 ✅
1 1 -2.6 0 1 ❌

学习规则（感知机规则）：

  • 预测错了，且目标为 1：说明阈值太高，给 w 和 b 都加上 lr × 输入
  • 预测错了，且目标为 0：说明阈值太低，给 w 和 b 都减去 lr × 输入
  • 预测正确：不调整

第 1 轮迭代

只有 (1,1) 错了，目标为 1。更新：

w₁ = -0.8 + 0.3×1 = -0.5
w₂ = -0.8 + 0.3×1 = -0.5
b  = -1.0 + 0.3×1 = -0.7

第 2 轮迭代

还是只有 (1,1) 错了，继续加 0.3：

w₁ = -0.5 + 0.3 = -0.2
w₂ = -0.5 + 0.3 = -0.2
b  = -0.7 + 0.3 = -0.4

第 3 轮迭代

再加一次：

w₁ = -0.2 + 0.3 = 0.1
w₂ = -0.2 + 0.3 = 0.1
b  = -0.4 + 0.3 = -0.1

现在验证 4 个样本：

x₁ x₂ z = 0.1x₁ + 0.1x₂ - 0.1 预测 目标
00-0.100 ✅
010.000 ✅
100.000 ✅
110.111 ✅

训练完成：神经元从「全猜 0」开始，经过 3 轮调整，最终找到了一个能完美实现 AND 门的参数组合。

关键观察：训练过程中，模型只在犯错的样本上调整参数。因为 (1,1) 这个目标为 1 的样本反复错，所以 w₁、w₂、b 被不断往上推，直到它跨过 0 阈值。这和人类学习很像——错题做多了，参数就往对的方向修正。

0.3 神经网络：把神经元堆起来

单个神经元能力很弱，但把很多神经元分层连接起来，就能表达复杂函数。

  • 输入层：接收原始数据（如图片像素、数字特征）
  • 隐藏层：位于中间的层，负责提取和组合特征
  • 输出层：给出最终预测（如是猫的概率、分类结果）

0.3.1 一个完整的前向计算例子

下面是一个 2→2→1 的网络，输入 2 个数，隐藏层 2 个神经元，输出 1 个数。我们用具体的权重和偏置，看数据怎么从输入流到最后输出。

网络参数

位置 权重 偏置 激活函数
隐藏神经元 1 w₁₁=0.2, w₁₂=0.4 b₁=0.1 tanh
隐藏神经元 2 w₂₁=-0.3, w₂₂=0.1 b₂=-0.2 tanh
输出神经元 v₁=0.5, v₂=-0.5 b_out=0.0 无

输入：x₁ = 0.5, x₂ = 1.0

第 1 层：隐藏层

z₁ = 0.2×0.5 + 0.4×1.0 + 0.1 = 0.10 + 0.40 + 0.10 = 0.60
h₁ = tanh(0.60) ≈ 0.5370

z₂ = -0.3×0.5 + 0.1×1.0 + (-0.2) = -0.15 + 0.10 - 0.20 = -0.25
h₂ = tanh(-0.25) ≈ -0.2449

第 2 层：输出层

out = 0.5×h₁ + (-0.5)×h₂ + 0.0
    = 0.5×0.5370 + (-0.5)×(-0.2449)
    = 0.2685 + 0.1225
    ≈ 0.3910

结果：输入 [0.5, 1.0] 经过这个网络后，输出约 0.39。如果这是房价预测，0.39 就是模型对这套房的预测值；如果是二分类，可以把它和 0 比较，大于 0 归为正类。

0.4 训练到底在做什么？

训练神经网络，本质上是一个「猜答案 → 看差多少 → 调整参数」的循环：

  1. 前向传播：输入数据，一层层算到输出，得到预测
  2. 计算损失：比较预测和真实答案，得到「错得多离谱」
  3. 反向传播：计算每个参数对损失的贡献（梯度）
  4. 更新参数：沿负梯度方向微调权重和偏置，让损失变小
输入数据 → 前向传播 → 计算损失 → 反向传播 → 更新参数

0.4.1 训练过程的数值例子

假设只有一个参数 w，当前值是 0.5。输入 x = 2.0 时，网络输出 0.5 × 2.0 = 1.0，但真实答案应该是 2.0。

第 1 步：计算损失

loss = (真实值 - 预测值)² = (2.0 - 1.0)² = 1.0

第 2 步：求梯度

梯度告诉我们：如果 w 增加一点，loss 会怎么变。

∂loss/∂w = 2 × (预测值 - 真实值) × x
        = 2 × (1.0 - 2.0) × 2.0
        = -4.0

梯度为 负数，说明 w 增大时 loss 会下降。

第 3 步：更新参数

学习率 lr = 0.1，更新规则是：

w = w - lr × ∂loss/∂w
  = 0.5 - 0.1 × (-4.0)
  = 0.5 + 0.4
  = 0.9

第 4 步：验证

更新后，同样输入 x = 2.0：

新输出 = 0.9 × 2.0 = 1.8
新损失 = (2.0 - 1.8)² = 0.04

损失从 1.0 降到 0.04，预测从 1.0 升到 1.8，更接近真实值 2.0。这就是训练一次的效果。

0.5 为什么需要非线性？

如果神经网络里只有乘法和加法，无论堆多少层，它都等价于一个线性函数：

y = W₂ × (W₁ × x + b₁) + b₂ = W × x + b

这样的网络只能画直线，无法处理弯曲的边界。就像前面说的 XOR 问题，单层神经元连一条斜线都画不出来，更别说多层线性堆叠。

直观例子：假设你要根据「学习时长」和「睡眠时长」预测「考试通过与否」。

  • 线性模型只能画一条直线：学习时间长就一定通过。
  • 但真实世界可能是：学习太短不通过，学习太长但睡眠不足也不通过。
  • 非线性模型（带激活函数）可以画出弯曲的决策边界，捕捉这种复杂关系。

激活函数（如 Tanh、Sigmoid、ReLU）的作用就是在神经元输出后引入非线性。没有它，再深的网络也只是一条直线。

0.6 几个必须知道的概念

权重 Weight

神经元对各个输入的重视程度。可正可负，可大可小。训练就是调整这些数字。

偏置 Bias

神经元的「触发阈值」。没有偏置，很多函数即使调整权重也无法拟合。

损失 Loss

预测与真实答案之间的差距。训练目标就是让损失越来越小。

梯度 Gradient

损失对每个参数的敏感度。告诉我们参数该往哪个方向调、调多少。

激活函数 Activation

给网络引入非线性。没有它，无论多少层都只能拟合直线。

学习率 Learning Rate

每次参数调整的步长。太大容易震荡，太小收敛太慢。

概念检查

  1. 神经网络用数据自动学习规律，而不是人工写规则
  2. 神经元 = 加权求和 + 偏置 + 激活函数
  3. 单个神经元能解决 AND、OR 等线性可分问题，但解决不了 XOR
  4. 多层网络前向传播就是逐层计算：输入 → 隐藏层 → 输出
  5. 训练 = 前向传播 → 算损失 → 反向传播 → 更新参数
  6. 梯度告诉我们每个参数该怎么调
  7. 没有激活函数，多层网络等价于单层线性变换，只能画直线

下一步：上面的例子中，前向传播、损失、梯度我们都是手算的。当网络变大、参数变多时，手动求梯度会变得非常困难。接下来你会学习 micrograd：一个用标量自动微分自动完成这些计算的引擎。

第 1 章：Value 对象与计算图

1.1 为什么需要自动微分？

训练神经网络时，我们需要不断调整参数（权重和偏置），让模型的预测越来越接近真实答案。调整的依据就是梯度：损失函数对每个参数的偏导数。

手动计算这些梯度非常繁琐，尤其是网络很深、参数很多的时候。自动微分（autograd）就是自动帮你算这些偏导数的工具。

一句话：自动微分让「求损失对百万参数的偏导」这件事变得自动化、可扩展。

1.2 micrograd 的核心设计

micrograd 用一个 Value 类代表一个标量。它不仅仅是一个数字，而是一个「会记录自己从哪里来、如何求导」的数字。

class Value {
    constructor(data, _children=[], _op='', label='') {
        this.data = data;                  // 当前标量的数值
        this.grad = 0.0;                   // 最终损失对这个标量的梯度
        this._backward = () => {};         // 一个闭包：如何把这个标量的梯度传回给子节点
        this._prev = new Set(_children);   // 产生这个 Value 的子节点集合
        this._op = _op;                    // 生成这个 Value 的运算符，如 +、*、**2
        this.label = label;                // 可读标签，方便 debug 和可视化
    }
}

字段详解

🔢data

含义：这个 Value 当前的数值。例如 new Value(2.0) 的 data 就是 2.0。

为什么需要：前向传播就是不断更新和组合这个字段，最终得到模型输出或损失值。

📉grad

含义：最终损失 L 对这个 Value 的偏导数，即 ∂L/∂this。

为什么需要：训练模型时，我们需要知道「如果把这个值稍微改变一点，损失会怎么变」。grad 就是这个敏感度。

初始为什么是 0：在 backward() 之前，我们不知道任何梯度。backward() 会把根节点的 grad 设为 1，然后逐步填充其他节点。

⬅️_prev

含义：产生当前 Value 的子节点集合（也就是「这个值是由哪些值算出来的」）。

为什么需要：反向传播时要沿着这些边往回走。如果不知道父亲是谁，就无法把梯度传回去。

🔧_op

含义：生成当前 Value 的运算符号，例如 +、*、**2。

为什么需要：画计算图时用来标注边，也帮助理解每个节点是怎么来的。

🏷️label

含义：人类可读的标签，比如 'x'、'w1'、'loss'。

为什么需要：调试和可视化时方便识别节点。它不参与计算。

🔄_backward（最关键）

含义：一个闭包函数，描述了「已知当前节点的上游梯度，如何计算并累加子节点的梯度」。

为什么需要：每个运算的求导规则不同。_backward 把「这个运算怎么反向传播」封装起来，让 backward() 可以统一调用。

例子：如果 c = a + b，那么 c 的 _backward 会执行：a.grad += c.grad; b.grad += c.grad;。

核心方法在做什么？

方法 前向做什么 反向做什么
add(other) 创建新 Value，data = this.data + other.data this.grad += out.grad; other.grad += out.grad
mul(other) 创建新 Value，data = this.data * other.data this.grad += other.data * out.grad; other.grad += this.data * out.grad
pow(n) 创建新 Value，data = this.data^n this.grad += n * this.data^(n-1) * out.grad
tanh() / relu() 应用激活函数得到新 Value 乘上激活函数的局部导数
backward() — 拓扑排序后，从根节点开始反向调用每个节点的 _backward，填充所有 grad

具体例子：Value 对象里到底存了什么？

看下面这行代码：

const a = new Value(2.0, [], '', 'a');
const b = new Value(3.0, [], '', 'b');
const c = a.mul(b);  // c = a * b

执行后，三个 Value 对象内部状态如下：

对象 data grad _op _prev label
a 2.0 0.0 '' 空集合 'a'
b 3.0 0.0 '' 空集合 'b'
c 6.0 0.0 '*' {a, b} ''

c.data = 6.0 是前向计算结果；_op = '*' 和 _prev = {a, b} 一起说明「c 是由 a 和 b 做乘法得到的」。这些信息就是反向传播时用的「地图」。

1.3 计算图长什么样？

当你写下 c = a + b 时，micrograd 会创建三个 Value 节点：a、b、c，并在 a、b 和 c 之间连上两条边，标记运算符为 +。

更复杂的表达式会形成更大的有向无环图（DAG）。这个图就是自动微分的基础：前向传播计算数值，反向传播沿着图的边回传梯度。

第 2 章：前向传播

2.1 什么是前向传播？

前向传播就是从输入开始，沿着计算图逐层计算出最终输出的过程。同时，它还会记录每个 Value 是如何由其他 Value 计算得到的。

以 c = a * b 为例：

  1. 创建 a 和 b 两个 Value
  2. 调用 a.mul(b)，得到 c，c.data = a.data * b.data
  3. c 的 _prev 包含 a 和 b，_op 是 *
  4. c 还保存一个 _backward 闭包，稍后用来自动求梯度
const a = new Value(2.0);
const b = new Value(3.0);
const c = a.mul(b);  // c.data = 6.0
const d = c.add(a);  // d.data = 8.0

2.2 每个运算都携带局部导数

前向传播时，每个运算不仅算出结果，还「预埋」了如何反向求导的逻辑。这就是 _backward 闭包的作用。

运算 前向 反向（局部导数）
加法 c = a + b c.data = a.data + b.data a.grad += c.grad; b.grad += c.grad
乘法 c = a * b c.data = a.data * b.data a.grad += b.data * c.grad; b.grad += a.data * c.grad
幂次 c = a^n c.data = a.data^n a.grad += n * a.data^(n-1) * c.grad

2.3 具体例子：一步步前向传播

看表达式 f = (a + b) * c，其中 a = 2.0，b = 3.0，c = 4.0。前向传播会逐次创建新节点：

const a = new Value(2.0, [], '', 'a');
const b = new Value(3.0, [], '', 'b');
const c = new Value(4.0, [], '', 'c');
const d = a.add(b);   // d = a + b
const f = d.mul(c);   // f = d * c
步骤 代码 计算 结果
1 a = 2.0, b = 3.0, c = 4.0 创建叶子节点 a=2, b=3, c=4
2 d = a + b d.data = 2 + 3 d=5, _op='+'
3 f = d * c f.data = 5 × 4 f=20, _op='*'

最终 f.data = 20.0。同时，计算图已经建好：d 依赖 {a, b}，f 依赖 {d, c}。反向传播时，就会沿着这些边从 f 往回走。

第 3 章：反向传播

3.1 反向传播的本质

反向传播（Backpropagation）是从最终输出（通常是损失）出发，沿着计算图把梯度传回给每一个参数的过程。

在 micrograd 中，调用 loss.backward() 会触发三个步骤：

  1. 拓扑排序：把所有节点按依赖顺序排好，确保每个节点在其子节点之后处理
  2. 根节点梯度置 1：损失对自己的导数是 1
  3. 反向遍历调用 _backward：从根节点开始，逐个调用每个节点预埋的反向传播闭包
backward() {
    const topo = [];
    const visited = new Set();

    function build(v) {
        if (!visited.has(v)) {
            visited.add(v);
            v._prev.forEach(build);
            topo.push(v);
        }
    }
    build(this);

    this.grad = 1.0;
    for (let i = topo.length - 1; i >= 0; i--) {
        topo[i]._backward();
    }
}

3.2 梯度如何传递？

每个节点收到上游梯度后，乘以自己这一层的局部导数，再分发给下游节点。这就是链式法则。

例如，如果 y = f(g(x))，那么：

dy/dx = dy/dg * dg/dx

在计算图中，dy/dg 是上游梯度，dg/dx 是局部导数，两者相乘就得到传给 x 的梯度。

3.3 具体例子：一步步反向传播

继续用上面的例子 f = (a + b) * c，其中 a=2, b=3, c=4，前向结果 f=20。现在调用 f.backward()，看看每个节点的 grad 怎么算出来。

第 0 步：拓扑排序

递归遍历得到 topo 数组（叶子先加入，根最后加入）：

topo = [a, b, c, d, f]

反向遍历顺序就是 f → d → c → b → a。

第 1 步：根节点 f 的梯度置 1

f.grad = 1.0

因为 f 对 f 的导数就是 1。

第 2 步：f = d * c 的反向传播

乘法规则：d.grad += c.data * f.grad，c.grad += d.data * f.grad

d.grad += 4.0 * 1.0 = 4.0
c.grad += 5.0 * 1.0 = 5.0

第 3 步：d = a + b 的反向传播

加法规则：a.grad += d.grad，b.grad += d.grad

a.grad += 4.0
b.grad += 4.0

最终结果

节点 data grad（∂f/∂该节点） 含义
a 2.0 4.0 a 增加 0.01，f 约增加 0.04
b 3.0 4.0 b 增加 0.01，f 约增加 0.04
c 4.0 5.0 c 增加 0.01，f 约增加 0.05
d 5.0 4.0 d 增加 0.01，f 约增加 0.04
f 20.0 1.0 损失对自己的导数

你可以手算验证：把 a 从 2 改成 2.01，f 从 20 变成 20.04，确实增加了 0.04。

概念检查

  1. 反向传播从最终输出开始，向输入回传梯度
  2. 拓扑排序确保处理顺序正确
  3. 每个节点把上游梯度乘以局部导数再传给子节点

第 4 章：链式法则与拓扑排序

4.1 多路径梯度累加

当一个 Value 被多个运算使用时，它会对最终输出产生多条路径的贡献。反向传播时，这些贡献要累加，而不是覆盖。

const a = new Value(2.0);
const b = a.add(1);  // b = a + 1
const c = a.add(2);  // c = a + 2
const d = b.mul(c);  // d = b * c

// 反向传播后，a.grad 应该包含两条路径的贡献
d.backward();
// a.grad = dc/da 经过 b 的贡献 + 经过 c 的贡献

这就是为什么 micrograd 的 _backward 使用 += 而不是 =。PyTorch 中也一样，所以每次 backward 前要 zero_grad()。

4.3 具体例子：多路径梯度累加

上面代码中，a=2，b=a+1=3，c=a+2=4，d=b*c=12。现在看 a 的梯度为什么是两路相加。

路径 1：d → b → a

  • ∂d/∂b = c = 4
  • ∂b/∂a = 1（因为 b = a + 1）
  • 所以 ∂d/∂a 经这条路径 = 4 × 1 = 4

路径 2：d → c → a

  • ∂d/∂c = b = 3
  • ∂c/∂a = 1（因为 c = a + 2）
  • 所以 ∂d/∂a 经这条路径 = 3 × 1 = 3

总梯度：∂d/∂a = 4 + 3 = 7。

你用手算验证：把 a 从 2 改成 2.01，则 b=3.01, c=4.01, d=3.01×4.01≈12.0701，增加了约 0.0701，和梯度 7 × 0.01 = 0.07 一致。

这就是 += 的原因：同一个节点可能通过多条路径影响输出，每条路径的贡献都要累加进来。

4.2 拓扑排序的作用

计算图是一个有向无环图（DAG）。反向传播必须按照「先子节点、后父节点」的顺序进行，否则梯度还没算完就被使用了。

拓扑排序正好给出这个顺序。micrograd 用递归深度优先遍历实现：

  • 访问一个节点前，先递归访问它的所有子节点
  • 等所有子节点都进入 topo 数组后，再把当前节点加入
  • 反向遍历 topo 数组，就是从根到叶子的正确顺序

一句话：拓扑排序让反向传播像「多米诺骨牌」一样，从输出一层层倒推到输入。

概念检查

  1. 多路径贡献的梯度要累加
  2. 拓扑排序保证反向传播顺序正确
  3. 每次训练前清零梯度是为了避免历史梯度干扰

第 5 章：激活函数

5.1 为什么需要非线性？

假设神经网络只有线性运算：

y = W2 * (W1 * x + b1) + b2

无论堆多少层，它都等价于一个线性变换 y = W * x + b。这样的网络只能拟合直线，无法处理弯曲的决策边界。

激活函数在神经元输出后引入非线性，让网络能够逼近任意复杂函数。

5.2 常见激活函数

Tanh

tan(x) = (e^x - e^{-x}) / (e^x + e^{-x})

输出范围 (-1, 1)，零中心化。两端会饱和，梯度接近 0。

Sigmoid

σ(x) = 1 / (1 + e^{-x})

输出范围 (0, 1)，适合概率解释。同样存在饱和问题。

ReLU

ReLU(x) = max(0, x)

计算简单，正区间梯度恒为 1。负区间梯度为 0，可能导致死神经元。

5.3 具体例子：激活函数算出来是多少？

以输入 x = 1.0 为例，计算三个激活函数的输出和导数：

激活函数 输出 f(x) 导数 f'(x) 数值结果
Tanh (e^x - e^{-x}) / (e^x + e^{-x}) 1 - tanh(x)^2 f(1.0) ≈ 0.7616，f'(1.0) ≈ 0.4200
Sigmoid 1 / (1 + e^{-x}) σ(x)(1 - σ(x)) f(1.0) ≈ 0.7311，f'(1.0) ≈ 0.1966
ReLU max(0, x) 1 if x>0 else 0 f(1.0) = 1.0，f'(1.0) = 1.0

如果输入是负数，比如 x = -2.0：

  • Tanh(-2.0) ≈ -0.9640，导数 ≈ 0.0707（接近饱和，梯度很小）
  • Sigmoid(-2.0) ≈ 0.1192，导数 ≈ 0.1050（也接近饱和）
  • ReLU(-2.0) = 0，导数 = 0（完全「死掉」，梯度无法回传）

这就是为什么深层网络训练时，Tanh/Sigmoid 容易出现梯度消失，而 ReLU 容易出现死神经元。

第 6 章：神经网络与训练

6.1 从 Neuron 到 MLP

micrograd 的 nn.py 用三个类搭建神经网络：

Neuron(nin)      → 接收 nin 个输入，计算加权求和 + 偏置，再经过激活函数
Layer(nin, nout) → nout 个 Neuron
MLP(nin, nouts)  → 多层 Layer，最后一层通常不用激活函数

每个 Module 都有 parameters() 方法，收集所有权重和偏置。训练时，优化器只更新这些参数。

6.2 训练循环

一个完整的训练步骤包括：

  1. 采样：取一个或一小批训练样本
  2. 前向：计算模型输出和损失
  3. 反向：调用 loss.backward() 求梯度
  4. 更新：用 SGD 按负梯度方向调整参数
  5. 清零：把 grad 置 0，准备下一轮
for epoch in range(100):
    # 前向
    loss = compute_loss(model, X, y)
    # 反向
    model.parameters().forEach(p => p.grad = 0);  // zero_grad
    loss.backward();
    # 更新
    model.parameters().forEach(p => {
        p.data -= learning_rate * p.grad;
    });
}

6.3 具体例子：一个神经元的一次训练迭代

假设我们有一个单输入神经元，要让它学会「输入 2.0 时输出接近 1.0」。真实标签 y = 1.0，学习率 lr = 0.1。

初始参数：权重 w = 0.5，偏置 b = 0.0，激活函数用 tanh。

第 1 步：前向传播

z = w * x + b = 0.5 * 2.0 + 0.0 = 1.0
output = tanh(1.0) ≈ 0.7616

第 2 步：计算损失

用平方误差损失： loss = (y - output)^2 = (1.0 - 0.7616)^2 ≈ 0.0568

第 3 步：反向传播

链式法则计算损失对 w 和 b 的梯度：

∂loss/∂output = 2 * (output - y) = 2 * (0.7616 - 1.0) = -0.4768
∂output/∂z = 1 - tanh(z)^2 = 1 - 0.7616^2 ≈ 0.4200
∂z/∂w = x = 2.0
∂z/∂b = 1

∂loss/∂w = -0.4768 * 0.4200 * 2.0 ≈ -0.4005
∂loss/∂b = -0.4768 * 0.4200 * 1 ≈ -0.2003

第 4 步：参数更新

w = w - lr * ∂loss/∂w = 0.5 - 0.1 * (-0.4005) ≈ 0.5401
b = b - lr * ∂loss/∂b = 0.0 - 0.1 * (-0.2003) ≈ 0.0200

结果：更新后 w 变大、b 变大，神经元输出会向 1.0 靠近。重复这个循环几十次， 输出就能接近目标值 1.0。

6.4 具体例子：一个完整 MLP 的定义、训练与预测

下面用一个极小的二层 MLP，把「定义网络 → 前向传播 → 计算损失 → 反向传播 → 更新参数 → 预测新样本」完整走一遍。为了让你能用手算验证，所有权重和偏置都是人工指定的。

第 1 步：定义网络结构

  • 输入层：2 个特征（x₁, x₂）
  • 隐藏层：2 个神经元，激活函数 tanh
  • 输出层：1 个神经元，无激活函数

用 micrograd 的 API 可以写成：

const model = new MGUtils.MLP(2, [2, 1], 'tanh');

第 2 步：人工指定初始参数

参数 初始值 说明
隐藏神经元 1 w₁₁=0.1, w₁₂=0.2, b₁=0.0 接收 x₁、x₂
隐藏神经元 2 w₂₁=-0.1, w₂₂=0.3, b₂=0.0 接收 x₁、x₂
输出神经元 v₁=0.5, v₂=-0.5, b_out=0.0 接收 h₁、h₂

第 3 步：前向传播

取一个训练样本： x₁ = 1.0, x₂ = 0.5，真实标签 y = 1.0。 

隐藏层：
z₁ = w₁₁·x₁ + w₁₂·x₂ + b₁ = 0.1×1.0 + 0.2×0.5 + 0.0 = 0.20
h₁ = tanh(z₁) = tanh(0.20) ≈ 0.1974

z₂ = w₂₁·x₁ + w₂₂·x₂ + b₂ = -0.1×1.0 + 0.3×0.5 + 0.0 = 0.05
h₂ = tanh(z₂) = tanh(0.05) ≈ 0.0500

输出层：
out = v₁·h₁ + v₂·h₂ + b_out = 0.5×0.1974 + (-0.5)×0.0500 + 0.0 ≈ 0.0737

第 4 步：计算损失

用平方误差损失：

loss = (y - out)² = (1.0 - 0.0737)² ≈ 0.8580

现在目标很明确：调整 9 个参数，让 loss 变小。

第 5 步：反向传播（核心梯度）

调用 loss.backward() 后，micrograd 自动算出每个参数的梯度。下面是几条关键梯度： 

∂loss/∂out = 2×(out - y) ≈ -1.8526

输出层：
∂loss/∂v₁ = ∂loss/∂out × h₁ ≈ -1.8526 × 0.1974 ≈ -0.3657
∂loss/∂v₂ = ∂loss/∂out × h₂ ≈ -1.8526 × 0.0500 ≈ -0.0926
∂loss/∂b_out = ∂loss/∂out ≈ -1.8526

隐藏层（以 w₁₁ 为例）：
∂loss/∂h₁ = ∂loss/∂out × v₁ ≈ -1.8526 × 0.5 ≈ -0.9263
∂h₁/∂z₁ = 1 - tanh(z₁)² ≈ 1 - 0.1974² ≈ 0.9610
∂loss/∂w₁₁ = ∂loss/∂h₁ × ∂h₁/∂z₁ × x₁ ≈ -0.9263 × 0.9610 × 1.0 ≈ -0.8902

其余参数类似。每个梯度告诉我们：这个参数往哪个方向调、调多少能让 loss 下降。

第 6 步：参数更新（SGD，lr = 0.1）

更新规则： 参数 = 参数 - 学习率 × 梯度 

v₁ = 0.5 - 0.1×(-0.3657) ≈ 0.5366
v₂ = -0.5 - 0.1×(-0.0926) ≈ -0.4907
b_out = 0.0 - 0.1×(-1.8526) ≈ 0.1853

w₁₁ = 0.1 - 0.1×(-0.8902) ≈ 0.1890
w₁₂ = 0.2 - 0.1×(-0.4451) ≈ 0.2445
b₁ = 0.0 - 0.1×(-0.8902) ≈ 0.0890

w₂₁ = -0.1 - 0.1×0.9240 ≈ -0.1924
w₂₂ = 0.3 - 0.1×0.4620 ≈ 0.2538
b₂ = 0.0 - 0.1×0.9240 ≈ -0.0924

第 7 步：预测新样本

用更新后的参数预测新样本 x₁ = 0.5, x₂ = 1.0： 

z₁ = 0.1890×0.5 + 0.2445×1.0 + 0.0890 ≈ 0.4280
h₁ = tanh(0.4280) ≈ 0.4030

z₂ = -0.1924×0.5 + 0.2538×1.0 + (-0.0924) ≈ 0.0652
h₂ = tanh(0.0652) ≈ 0.0651

out = 0.5366×0.4030 + (-0.4907)×0.0651 + 0.1853 ≈ 0.3699

训练前输出约 0.07，训练一步后预测新样本输出约 0.37，方向朝正数（标签为 1 的方向）移动。如果继续用更多样本迭代训练，输出会逐步接近真实标签。

完整流程回顾

定义 MLP → 前向算输出 → 算损失 → 反向求梯度 → SGD 更新 → 预测新样本
