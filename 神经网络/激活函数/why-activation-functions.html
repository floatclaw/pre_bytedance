1. 从生物神经元到阶跃函数

神经网络最早的想法来自对生物神经元的模仿。

一个生物神经元大致是这样工作的：它从其他神经元接收许多信号，把这些信号加权汇总，如果汇总后的强度超过某个阈值，神经元就"激活"，向外发出信号；否则保持沉默。

上世纪 40 年代，McCulloch 和 Pitts 把这个过程抽象成了一个数学模型：

output = 1  if w1*x1 + w2*x2 + ... + b >= 0
output = 0  otherwise

这就是阶跃函数（Step Function）。它是神经网络上最早的"激活函数"。

用这个模型，单个神经元可以学会一些简单的规律。比如 AND 门：当两个输入都为 1 时输出 1，否则输出 0。

假设我们找到这样一组参数：

  • • 权重：w1 = 0.5，w2 = 0.5
  • • 偏置：b = -0.7

那么对于 4 个输入：

x1x2加权求和 z = 0.5x1 + 0.5x2 - 0.7阶跃输出
00-0.70
01-0.20
10-0.20
110.31

结果完全正确。同样，如果用 w1 = 0.6、w2 = 0.6、b = -0.3，神经元就能学会 OR 门：只要有一个输入为 1，输出就是 1。

此时的神经元很直观：加权求和，超过阈值就输出 1，否则输出 0。

2. 从单层到多层：激活函数如何带来"曲线"？

但单个神经元的能力是有限的。

它只能解决线性可分的问题。什么意思？就是说，如果画一条直线就能把不同类别的样本分开，那单个神经元就能学会；如果分不开，就无能为力。

AND 和 OR 都是线性可分的。你可以想象在平面上画一条直线，把输出为 1 的点（比如 AND 中的 (1,1)）和输出为 0 的点分开。但 XOR 不行。

XOR 问题就是最典型的例子：

x1x2y
000
011
101
110

在二维平面上，两个正例 (0,1) 和 (1,0) 位于对角，两个负例 (0,0) 和 (1,1) 位于另一对角。无论你画哪条直线，都不可能把正例和负例完全分开。

那怎么办？答案是多加几层神经元。

思路是：第一层神经元分别画出几条不同的直线边界，把平面划分成不同的区域；第二层神经元再把这些区域组合起来。多个直线边界拼接在一起，就能围出曲线、折线、甚至任意复杂的形状。

比如 XOR 可以这样解决：

  • • 第一个隐藏神经元学会区分"x1 + x2 >= 1"（右上方区域），对 (0,1) 和 (1,0) 输出 1
  • • 第二个隐藏神经元学会区分"x1 + x2 <= 1"（左下方区域），对 (0,0) 和 (1,1) 输出 1
  • • 输出层把这两个信号组合：当且仅当"在右上方区域但不在左下方区域"时输出 1

你可以把它理解为：先用两条直线把平面切成几块，再用第三层决定哪一块属于正例。单个神经元只能画直线，但多个神经元通过激活函数组合，就能把直线拼接成折线，把折线再逼近成曲线。

关键直觉：激活函数让每个神经元不再只是做线性加权，而是像一个"开关"——某些神经元在某些区域被打开，在另一些区域被关闭。网络通过组合这些开关，把简单的直线变成复杂的曲线。

但这里有一个更根本的问题：如果神经网络里只有线性运算，那无论堆多少层，最终都等价于一个线性模型。

证明很简单：

第一层：h = W1 * x + b1
第二层：y = W2 * h + b2
        = W2 * (W1 * x + b1) + b2
        = (W2 * W1) * x + (W2 * b1 + b2)
        = W' * x + b'

两层线性变换叠加，仍然只是一个线性变换。没有激活函数，再深的网络也只是"一条更复杂的直线"，永远无法拟合曲线边界。

所以，激活函数是神经网络从"直线模型"变成"曲线拟合器"的关键。

3. 神经网络要学习，学习要求激活函数可导

我们已经知道：多层网络需要非线性激活函数来表达复杂边界。

但神经网络不是手动设计出来的，而是学习出来的。

一个神经网络可以写成：

模型 = 结构 + 参数

结构是固定的，学习的目标就是找到一组好的参数（权重和偏置），让模型的预测尽可能接近真实答案。

现代神经网络主要用梯度下降来寻找参数。可以把它想象成在山上找最低点：你蒙着眼睛站在山坡上，只能通过脚下的坡度判断方向，然后一步一步往坡下走。梯度就是告诉你"哪个方向最陡"的那根指南针。

具体步骤是：

  1. 1. 定义一个损失函数，衡量预测和真实答案之间的差距
  2. 2. 计算损失函数对每个参数的梯度
  3. 3. 沿着梯度的反方向调整参数，让损失变小
  4. 4. 重复直到收敛

而梯度的计算，依赖反向传播。

反向传播的核心是链式法则。举个简单例子：

y = 2 * x
L = y * y

如果 x = 3，那么 y = 6，L = 36。现在问：x 增加一点点，L 会怎么变？

  • • dL/dy = 2*y = 12
  • • dy/dx = 2
  • • 所以 dL/dx = dL/dy * dy/dx = 12 * 2 = 24

也就是说，x 增大 0.01，L 大约增加 0.24。神经网络有成千上万层这样的关系，反向传播就是把这种链式求导一层一层传回去。

这要求激活函数必须可导。

现在回头看阶跃函数：

f(x) = 0  if x < 0
f(x) = 1  if x >= 0

它的图像在 x = 0 处突然从 0 跳到 1，是一个不连续的跳跃。在 x < 0 和 x > 0 的地方，导数都是 0；在 x = 0 处，导数不存在。

举个具体例子：假设某个神经元的输入刚好是 -0.1，输出为 0。你把这个神经元的权重稍微调大一点，输入变成了 0.1——还没越过 0，输出仍然是 0。再调大一点，输入一旦超过 0，输出突然变成 1。在整个过程中，输出的变化不是平滑的，而是"跳"了一下。

这意味着什么？

  • • 如果参数的变化没有让神经元的输入越过阈值，输出不变，梯度为 0，参数不会更新
  • • 即使输入刚好在阈值附近，导数也没有定义，无法确定该往哪个方向调整
  • • 反向传播传到阶跃函数这里，梯度就断了

所以，阶跃函数虽然能表达非线性，但它无法支持学习。多层阶跃网络在理论上可以表示 XOR，但你没办法用梯度下降把它训练出来。

4. 从阶跃函数到 Sigmoid：不可导变成可导

既然阶跃函数不可导，那自然的想法就是：找一个形状类似，但光滑、可导的函数来替代它。

Sigmoid 就是这样一个函数：

σ(x) = 1 / (1 + e^(-x))

它的图像和阶跃函数很像：

xσ(x)阶跃函数 f(x)
-30.0470
00.5001（或 0，取决于定义）
30.9531
  • • 当 x 很小（负无穷）时，σ(x) 接近 0
  • • 当 x 很大（正无穷）时，σ(x) 接近 1
  • • 当 x = 0 时，σ(x) = 0.5

但和阶跃函数最大的区别是：Sigmoid 是光滑的。它在每一点都有明确的导数，图像是一条连续变化的 S 型曲线，没有跳跃。

比如 x = 0 处，Sigmoid 的输出是 0.5，导数是 0.25。这意味着：如果权重有微小调整，输出会平滑地变化一点点，同时我们知道该往哪个方向继续调整。

Sigmoid 的导数还有一个非常简洁的形式：

σ'(x) = σ(x) * (1 - σ(x))

这个性质让反向传播变得容易计算。

效果是什么？

  • • 反向传播可以正常把梯度从输出层传回输入层
  • • 每个参数都能得到一个非零的梯度（至少在大部分区域）
  • • 参数可以沿着梯度方向逐步调整
  • • 多层网络真正变得"可学习"

换句话说，Sigmoid 保留了阶跃函数"把数值压缩到 0 和 1 之间"的非线性特性，同时补上了"可导"这个关键的数学条件。

其他常用的激活函数也遵循类似的思想：

  • • Tanh：可以看作 Sigmoid 的对称版本，输出在 -1 到 1 之间，同样处处可导
  • • ReLU：ReLU(x) = max(0, x)，虽然 x = 0 处导数不唯一，但其他位置导数简单，计算高效，缓解了深层网络中的梯度消失问题

它们都是在"非线性表达"和"可训练性"之间寻找更好的平衡。

5. 总结

激活函数在神经网络里承担两个核心角色：

第一，引入非线性。

没有激活函数，多层网络就退化成一个线性模型，无论多深都只能画直线。激活函数让网络能够表达曲线、折线、复杂的决策边界，从而解决 XOR 这种非线性可分问题。

第二，保证可导。

神经网络要通过梯度下降来学习，而梯度下降需要求导。阶跃函数虽然是非线性的，但它几乎处处导数为 0，在关键点不可导，导致反向传播无法进行。Sigmoid、Tanh、ReLU 等激活函数在保留非线性的同时，提供了可导性，让网络真正可以被训练。

从阶跃函数到 Sigmoid，再到 ReLU，本质上都是在回答同一个问题：

如何设计一个函数，既能给网络足够的表达能力，又能让网络通过梯度下降高效地学习？

激活函数的选择，就是在这个矛盾中寻找最合适的平衡点。
